- **Фирменный стиль:** Создан на основе золотого логотипа-аватарки клиента (Chispa) на матовом графитово-черном фоне.

- **Mobile-First:** Полная адаптивность под смартфоны (iPhone, Android) с плавающей кнопкой записи в WhatsApp.
